**Проект для портфолио — Ксения Самохина**  
[English version](README.md)

## Описание проекта

HomeRoute — учебная компания в сфере доставки. Проект посвящён анализу своевременности доставки, работы перевозчиков, транспортных расходов и региональных различий. Интерактивный отчёт помогает операционным менеджерам отслеживать KPI и находить потенциальные проблемы логистики.

## Цель проекта

- Отслеживать количество заказов, долю своевременных доставок, средний срок доставки, стоимость доставки одного заказа и количество задержек.
- Сравнивать перевозчиков и регионы.
- Исследовать показатели с помощью фильтров по датам, регионам, городам, товарам, перевозчикам и статусам доставки.

|---|---:|
| Всего заказов | 1 700 |

| Средняя продолжительность доставки | 4,74 дня |
| Стоимость доставки на заказ | 12,78 |

## Основные результаты

- **Своевременность:** показатель 84,56% указывает на возможности повышения качества доставки.
- **Перевозчики:** отчёт позволяет сравнивать число задержек и стоимость доставки. Абсолютное количество задержек нельзя напрямую считать долей задержек без учёта объёма заказов.
- **Регионы:** своевременность доставки различается по регионам; интерактивные фильтры помогают находить проблемные сочетания региона и перевозчика.
- **Расходы:** стоимость доставки различается по перевозчикам, поэтому полезно сопоставлять расходы с качеством обслуживания.

## Что реализовано

- Трёхстраничный интерактивный Power BI-отчёт: KPI, динамика заказов, сравнение перевозчиков, региональные таблицы и детализация заказов.
- DAX-меры для расчёта заказов, своевременности, сроков доставки, стоимости и задержек.
- Преобразования Power Query (M): импорт файлов, назначение типов, обработка числовых значений и удаление дубликатов.

## Как открыть проект

1. Скачайте `HomeRoute_Delivery_Analytics.pbix` и откройте его в **Power BI Desktop**.
2. Изучите три страницы и интерактивные фильтры.
3. Для обновления данных настройте пути к источникам на своём компьютере. Исходные наборы данных в репозиторий не включены.
4. Без Power BI Desktop можно посмотреть `Dashboards.pdf` и изображения выше.
